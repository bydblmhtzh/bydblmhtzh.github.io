四种 SQL 建表方式

2026-07-20 · 1 分钟阅读 · #SQL#数据库
目录

创建一个表：
CREATE TABLE opening AS
SELECT name FROM pizzas WHERE open <13 ORDERED BY name DESC;
(获取下午一点前能吃到披萨的店名)

创建任意条件限制的表：
CREATE TABLE study AS
SELECT name, MAX(14 - open, 0) AS duration FROM pizzas ORDERED BY duration DESC;
(我在下午两点前能带够多长时间的表)

一个输出字符串的表：
CREATE TABLE late AS
SELECT name || “ closes at “ || close AS status FROM pizzas， meals WHERE meal = “snack”

– 在同一地点吃两顿饭
CREATE TABLE double AS
SELECT a.meal AS first, b.meal AS second, name
FROM meals AS a, meals AS b, pizzas
WHERE open <= a.time AND a.time <= close AND
open <= b.time AND b.time <= close AND
b.time > a.time + 6;
