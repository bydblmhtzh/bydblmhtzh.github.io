Normal Shader 的原理（镜像 UV）

#镜像UV
镜像 UV（Mirrored UV）是指 3D 模型的两个不同面共享同一个纹理，但 UV 坐标方向相反。

举个具体例子：角色脸部

多数角色模型只做半边脸，然后”对称镜像”得到另一边：

      左脸 UV                    右脸 UV (镜像)
  (0,0)----(0.5,1)          (0.5,1)----(0,0)
    |    ←    |                |    →    |
    |  U方向  |                |  U方向  |
    |         |                |         |
  (0,1)----(0.5,1)          (0.5,1)----(1,1)

  同纹理，U轴方向相反

美术只画半边脸的纹理，引擎自动把右脸镜像过去。但这样右脸的 Tangent、Normal、Binormal 方向就变了。

#UV与TBN的关系
切线空间（TBN）的坐标系取决于面片的朝向：

  • Tangent (T)：指向 UV 的 U 轴方向
  • Binormal (B)：指向 UV 的 V 轴方向（通常这样）
  • Normal (N)：面的法线方向

正常面： 镜像面：
T → ← T (U 翻转)
B ↑ B ↑ (V 不变)

所以法线不对了，T必须增加w维度
